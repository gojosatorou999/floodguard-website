        Data provenance

        What is real, what is modelled, what is placeholder.

        A map that looks convincing is worth little if you cannot tell which parts are measured. Here is every source behind the studio.

        Real data

        Fetched at runtime

        • Elevation — Mapzen / AWS Terrain Tiles (SRTM, ASTER, GMTED); bundled ETOPO1 as an offline fallback
        • Satellite — NASA VIIRS true colour via GIBS
        • Rainfall — NASA GPM IMERG rain rate via GIBS
        • Boundaries and rivers — DataMeet districts, Natural Earth
        Derived

        Computed in your browser

        • Drainage network — priority-flood flow routing and accumulation on the real terrain
        • Hazard probability and flood depth — a screening model on height above nearest drainage (HAND), with stage rising by return period and stream size
        • Shading — slope, sky-view occlusion, contours
        Simulated

        Placeholder until real data is wired in

        • Population and assets — a seeded settlement model; swap for WorldPop / OSM
        • Climate projections — coarse warming curves and illustrative district sensitivities
        • Historical flood index — a terrain / river / coast heuristic, with real recorded events marked
        • Design storm over the 3D window
